# Anti-slop audit 001: Carlos Nunez site

Date: 2026-10-09  
Mode: After  
Source: [anti-slop core rules](https://github.com/miqdadbadjuber/anti-slop/blob/main/antislop.md)

## Direction and scope

The site's existing direction is documented in `CLAUDE.md`: a neutral PaperMod palette, a centered and unframed profile, and ASCII waves as the homepage motif. The owner has rejected OS-style window chrome, glass panels, and mint accents. I treated that direction as authoritative. An inferred read of the current design is ENERGY 1 (restrained), RHYTHM 1 (simple), MOTION 2 (ambient homepage motion). This is an observation, not a new design brief.

I reviewed the Hugo source and production build, then checked the rendered home, contact, posts, one NodeStrike post, categories, tags, and search pages in Chrome. I checked both homepage themes and the NodeStrike post at a 400px responsive viewport. `make build` passed with Hugo 0.147.7. I did not submit the contact form or follow external links. This is an audit of the local build, not a claim that every production interaction was exercised.

## Numbered findings

1. **HIGH — Broken “Suggest Changes” link (R-26, Interactive Elements).** `hugo.yml:121-124` still uses `https://github.com/<path_to_repo>/content`. The production build renders a link to `github.com/%3cpath_to_repo%3e/...` on the NodeStrike post, so the visible action cannot reach this site's repository. Set the real repository URL or remove the action.

2. **HIGH — Template metadata is published as site identity (R-38, Real Content or Honest Placeholder).** `hugo.yml:37-42` sets the site name and description to `ExampleSite` and `ExampleSite description`, plus a placeholder Open Graph image. The generated home page publishes those strings as its meta description, Open Graph site name, and image URL. Replace them with verified Carlos Nunez content and a real image, or omit the image.

3. **HIGH — Empty content views give no explanation (R-27, UI States).** The navigation links in `hugo.yml:138-149` lead to `/categories/` and `/tags/`, which currently show only a title and an empty list. Search likewise shows an empty list after a query with no matches. Add a clear empty/no-results message; populate taxonomies or reconsider whether those navigation items serve visitors. Evidence: no published post declares `categories` or `tags` front matter, and the rendered pages were empty.

4. **HIGH — Contact placeholder text misses AA contrast (R-25, Color Contrast).** `assets/css/extended/custom.css:266-270` applies `opacity: 0.6` to `var(--secondary)` placeholders. Against the input background, the computed contrast from the CSS values is about **2.31:1 in light mode** and **2.50:1 in dark mode**, below the 4.5:1 normal-text target. Increase placeholder contrast in both modes. Keep visible labels, which are already present.

5. **HIGH — Several tap targets are below 44px (R-03, Mobile Responsiveness).** The theme toggle and social icon links are 40×40px, and the Contact Me link has a 40px minimum height (`assets/css/extended/custom.css:37-45`, `119-127`, `159-165`). Chart buttons have 6px vertical padding around 14px text (`assets/css/extended/graphs.css:10-13`), making their target shorter than 44px. Increase interactive hit areas while preserving the site's compact visual style. The sampled 400px post layout itself did not visibly clip.

6. **LOW — The posts index mixes site pages with articles (R-05, Layout & Page Structure).** `content/Posts/Terms.md` and `content/Posts/aboutme.md` appear as entries in `/posts/`. The cookie policy is presented as a post with a large raw HTML excerpt, and About Me duplicates the separate homepage action. Move or exclude non-articles from the article list so the list reflects the writing visitors came to browse.

7. **LOW — Internal work notes appear in a published article (R-05, Layout & Page Structure).** `content/Posts/nodeStrikeExecution.md:246-271` renders a `TODO` section with unchecked tasks and internal reminders after the article. Move those notes to a draft or project file, or rewrite them as a reader-facing “Next steps” section when ready.
